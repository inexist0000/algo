# PBL 지도 편집기

`python utill.py`로 실행합니다. Python의 tkinter가 필요합니다.
PNG는 추가 설치 없이 지원합니다. JPG 등을 쓰려면 `pip install Pillow`로 Pillow를 설치하세요.

1. **지도 불러오기**: 준비한 지도 사진을 선택합니다. 원본 크기로 표시하며 스크롤할 수 있습니다. 사진은 assets/campus.*로 복사됩니다.
2. **노드 추가**: 지도 위를 클릭하고 이름을 입력합니다.
3. **선택 / 위치 이동**: 노드를 클릭하면 오른쪽에서 이름과 좌표를 수정할 수 있습니다. 드래그로 위치도 옮깁니다.
4. **구간 연결**: 출발 노드와 도착 노드를 순서대로 클릭하고 기본 시간을 초 단위로 입력합니다.
5. 구간 선이나 오른쪽 목록을 선택하여 기본 시간과 혼잡 추가 지연을 수정하고 **변경 적용**을 누릅니다.
6. **저장** 또는 Ctrl+S로 data/graph.json에 저장합니다. 다음 실행 때 자동으로 불러옵니다.

연결은 방향별로 저장됩니다. 왕복 길은 양방향을 각각 추가하세요. 기본 시간은 경사와 계단을 포함한 평상시 통과 시간이고, 혼잡 시간의 비용은 weight + peak_delay입니다. 가중치는 노드가 아닌 구간에 설정합니다.

좌표는 지도 이미지의 왼쪽 위를 (0, 0)으로 하는 원본 픽셀 좌표입니다. 위도·경도가 아닙니다. 나중에 같은 이미지에 그릴 때 그대로 사용하면 됩니다. 이미지 교체 시 기존 그래프는 확인 후 초기화됩니다.

graph.json 구조: image(path, width, height), nodes(id, name, x, y), edges(source, target, weight, peak_delay). main.py와 grap.py는 수정하지 않습니다.

지도 이미지는 아직 제공되지 않아 포함하지 않았습니다. 첫 실행에서 직접 선택하세요. 사진에 대한 사용 권한과 출처는 유지하세요.

## 좌표와 높이
검은색 테마를 사용합니다. 마우스 위치는 하단에 원본 이미지 픽셀 좌표로 표시됩니다. 노드 추가 시 클릭 위치를 기본값으로 X/Y를 직접 수정하고 고도(m)를 입력합니다. 고도를 모르면 취소하여 미지정(null)으로 두세요. 선택한 노드의 오른쪽 높이 입력란에서도 수정할 수 있으며 빈칸은 미지정입니다. 음수 고도도 허용합니다. elevation_m은 수동 입력 값이며 이미지에서 자동 추출되지 않습니다. 기존 노드 데이터도 그대로 읽습니다. 지도 사진 자체의 색상은 유지됩니다.

노드 추가는 지도 클릭 후 이름만 입력합니다. 클릭 좌표가 자동 저장되고 높이는 기본 0m입니다. 좌표와 높이는 오른쪽 선택 항목에서 나중에 수정할 수 있습니다.
